 Currículo (AtCurriculo) 📄✨

Repositório voltado para a criação, estruturação e customização de currículos profissionais utilizando tecnologias web, permitindo uma apresentação limpa, moderna e estruturada de experiências e habilidades.

---

## 🚀 Funcionalidades

- **Layout Profissional:** Estrutura limpa e organizada focada em legibilidade para recrutadores.
- **Seções Essenciais:** Espaços dedicados para dados pessoais, resumo profissional, histórico acadêmico, experiências profissionais e competências.
- **Responsividade:** Design adaptável para visualização em diferentes dispositivos e pronto para exportação/impressão em PDF.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e hierárquica do currículo.
- **CSS3:** Estilização visual, fontes elegantes e regras de formatação para impressão.
- **JavaScript (Vanilla):** (Opcional) Funcionalidades dinâmicas para interatividade ou preenchimento automatizado.
